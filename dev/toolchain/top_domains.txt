# top_domains.txt — the most popular domains that serve HTTPS, in rank order.
#
# dev/toolchain/test_top_sites.sh fetches https:// for the first N of these and
# turns the result into a number: how much of the popular web this client can
# actually talk to. The number is the test. A trust store that quietly loses a
# third of its anchors, a TLS 1.3 parameter the web has moved past, a
# certificate profile rule that is too strict -- none of those show up in a
# fixture suite, and all of them show up here as a count that fell.
#
# Source: the Tranco research ranking (https://tranco-list.eu/), list V3YPN,
# generated 2026-09-17 over the 30 days ending 2026-09-17, combining the CrUX,
# Farsight, Majestic, Cloudflare Radar and Umbrella rankings by the Dowdall
# rule, pay-level domains only. Tranco exists because the single-provider top
# lists disagree wildly and are trivially manipulated, and it is the one to
# cite:
#
#   V. Le Pochat, T. Van Goethem, S. Tajalizadehkhoob, M. Korczynski and
#   W. Joosen, "Tranco: A Research-Oriented Top Sites Ranking Hardened Against
#   Manipulation", NDSS 2019.
#
# Filtered once, when it was frozen: the ranking's top 1,500 apex domains were
# each offered a TLS handshake on port 443 with `openssl s_client`, and the
# first 1,000 that completed one, in rank order, are what is below. The
# filtering matters because a popularity ranking is not a list of websites --
# akamai.net, domaincontrol.com and ezviz7.com rank high and serve no page on
# the apex at all -- and a suite that counted those as failures would be
# measuring DNS trivia rather than this client. What is filtered OUT is only
# "nothing answered TLS here"; a host that answers and then fails to
# authenticate is exactly what this list is for, and stays in.
#
# Frozen deliberately rather than downloaded at test time: a suite whose input
# moves underneath it cannot tell a regression in word from a reshuffle in the
# ranking, and CI must not depend on a third party being up. Refresh it on
# purpose, in its own commit, and re-measure the baselines in
# test_top_sites.sh in that same commit.
